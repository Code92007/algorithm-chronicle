# 编纂约定

正文使用现代汉语，尽量简短。不为平台、人物或学校作价值排名，不通过省略已知事实制造单方面结论。

## 事实与来源

1. 时间、奖项优先使用主办方公告、原始赛页、最终榜单或高校一手资料。
2. 网站创建、公司成立、首场比赛是不同事件，不互相替代。
3. 赛事按赛季/官方届次归档，实际比赛日期单独保留。
4. 官方奖项、社区榜单奖牌区间和赛事索引分别标记。原始名单缺失时不推定获奖。
5. 所有摘要为简写，原文仍归各来源；不转载整篇文章或知乎回答。

## 公共议题

记录经过、材料来源和核验边界。质疑者的材料注明其立场；回应入口与质疑材料并列。无法核验的原页只保留链接，不据以转述结论。未收录正式裁决时，不将具体人员或队伍定性为违规。

## 现有局限

- 平台列传为七篇简记，尚未覆盖所有 OJ。
- 年表以 2020—2025 年中国境内赛站为主，未覆盖全部东亚赛站及所有年份。
- 部分社区档案含未判定记录、学校字段为空、分组/奖项格式不支持或未完整下载，保留原始入口。
- 银川争议条目没有完整核验知乎、微博原文，未作裁决或责任认定。
- AtCoder AI 条目是规则沿革，不声称已证实为知乎热议。

## 勘误材料

请提供条目、原句、建议修订、支持来源和来源日期。修订事实时同步更正筛选字段、摘要和年表数据；保留 Git 修订记录。

## 社区数据复现

保存 GitHub `git/trees/<revision>?recursive=1` 的 JSON，在顶层额外写入 `commit` 字段，值为对应的完整 commit SHA。不要以 Git tree 对象 SHA 代替 commit SHA。导入器将原始文件缓存到指定目录。

```sh
python3 scripts/import_archive.py --tree /path/to/tree.json --cache /path/to/cache
python3 scripts/merge_official.py --scoreboard-2025 /path/to/wf2025.html
```

`--offline` 仅使用已缓存的配置和提交文件。读取、重建均只处理显式支持的格式。CCPC 的 `ccpc` 预设按正式组中有解题的队伍数计算 10%、30%、60% 的累计边界，分别向上取整；其余仅读取配置中的明确配额。罚时与平分规则参照 XCPCIO 的 `packages/libs/core/src/{rank,team,submission-status}.ts`，结果仍标为社区归档。发布前应核对导入报告并执行测试；官方奖项合并必须在社区导入之后运行，避免被后者覆盖。
